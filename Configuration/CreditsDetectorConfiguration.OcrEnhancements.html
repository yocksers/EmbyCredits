Advanced Options!

Only use if you know what they do as they can greatly change detections

OCR Enhancements

Advanced features to improve OCR detection accuracy and performance. All features are disabled by default.

Note: To choose between Tesseract and PaddleOCR engines, go to the Settings tab and select your preferred OCR Engine.

Tesseract Language Configuration

Configure Tesseract OCR engine for better multi-language support, especially Japanese text with spacing. Only applies when Tesseract is selected.

Default: eng+jpn. Language codes separated by + (e.g., "eng+jpn+kor"). Common: eng (English), jpn (Japanese), kor (Korean), chi_sim (Chinese Simplified), chi_tra (Chinese Traditional), spa (Spanish), fra (French), deu (German)
Default: 3. How Tesseract segments the page. 3=Auto (recommended), 6=Single uniform block, 11=Sparse text, 12=Sparse text with OSD, 13=Raw line
Default: 3. 0=Legacy, 1=LSTM only, 2=Legacy+LSTM, 3=Default (LSTM if available). LSTM (mode 1 or 3) works better for Japanese
Essential for Japanese shows with spaces between characters. Preserves spacing in OCR output for accurate keyword matching

Credit Structure Detection

Recognize typical credit formatting (uppercase roles + mixed case names) without keywords.

Detect credits by formatting patterns (e.g., "DIRECTOR" followed by "John Smith")
Default: 4. Minimum text lines required to analyze structure

Adaptive Frame Rate

Dynamically reduce sampling rate once credits are detected to improve performance.

Reduce frame sampling after initial detection while maintaining accuracy
Default: 0.25. Minimum FPS to drop to (prevents under-sampling)

Scrolling Pattern Detection

Detect rolling credits by analyzing text movement across frames, even without keywords.

Detect credits by identifying continuous scrolling text motion
Default: 5. Consecutive frames needed to confirm scrolling pattern
Default: 0.3. Text overlap ratio to qualify as scrolling (0.3 = 30% overlap between frames)

Fuzzy Keyword Matching

Match keywords even when OCR makes minor errors (e.g., "directed" matches "dinected").

Use Levenshtein distance to match keywords with minor OCR errors
Default: 2. Maximum character differences allowed (1-3). Distance 2: "produced" matches "produccd"

Region of Interest (ROI)

Focus OCR on specific screen regions where credits typically appear for faster processing. Should not be used by anyone other than for trying to redetect in failed videos.

Crop frames to focus on regions where credits typically appear
Choose the screen region to analyze. Bottom third is best for scrolling credits

Sharpening

Apply unsharp mask to enhance text edges for better recognition.

Apply unsharp mask to enhance text edges for better recognition
Default: 1.0. Sharpening intensity (0.0-2.0). Higher values = sharper but may introduce artifacts

Image Preprocessing

Enhance frame quality before OCR to improve text recognition, especially for low-quality sources.

Apply contrast and brightness adjustments to improve OCR accuracy
Default: 1.5. Adjust image contrast (1.0 = no change, >1.0 = increase). Range: 1.2-2.0 for most videos
Default: 0.05. Adjust brightness (-1.0 to 1.0). Use 0.1 for dark videos, -0.1 for bright ones
