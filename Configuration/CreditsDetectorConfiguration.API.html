API Endpoints

The Credits Detector plugin provides comprehensive REST APIs for triggering detection, configuring settings, and retrieving results.

Detection Control

POST /CreditsDetector/StartDetection

Unified endpoint for starting credits detection with custom settings

Request Body:

{
    "EpisodeId": "string (optional)",
    "SeriesId": "string (optional)",
    "SeasonNumber": number (optional),
    "LibraryId": "string (optional)",
    "SkipExistingMarkers": boolean,
    "DryRun": boolean,
    "EnableDebugLogging": boolean,
    "SettingsOverride": {
        "DetectionMode": "OcrOnly|HashOnly|OcrWithHashFallback|HashWithOcrFallback",
        "OcrEngine": "Tesseract|PaddleOCR",
        "OcrEndpoint": "string",
        "OcrLanguages": "string",
        "OcrDetectionKeywords": "string",
        "OcrSearchStartValue": number,
        "OcrMinutesFromEnd": number,
        "OcrFrameRate": number,
        "OcrMinimumMatches": number,
        "OcrMaxFramesToProcess": number,
        "OcrEnableEpisodeComparison": boolean,
        "OcrEpisodeComparisonTolerance": number,
        "OcrEnableCharacterDensityDetection": boolean,
        "OcrCharacterDensityThreshold": number,
        "EnableAnimeDetection": boolean,
        "AnimeDetectionMethod": "BlackFrame|Ocr",
        "CpuUsageLimit": number,
        "EnableVideoValidation": boolean,
        "VideoValidationTimeoutSeconds": number
    }
}

Use Cases:

  • Process specific episode: Include EpisodeId
  • Process entire season: Include SeriesId and SeasonNumber
  • Process entire series: Include SeriesId only
  • Process library: Include LibraryId
  • Test settings: Set DryRun: true
  • Debug detection: Set EnableDebugLogging: true

Settings Override: All settings are optional. If omitted, plugin defaults are used.

POST /CreditsDetector/ProcessEpisode

Process a specific episode by ItemId

Request Body: { "ItemId": "string", "SkipExistingMarkers": boolean }

POST /CreditsDetector/ProcessSeries

Process all episodes in a specific TV series

Request Body: { "SeriesId": "string", "SkipExistingMarkers": boolean }

POST /CreditsDetector/ProcessSeason

Process all episodes in a specific season

Request Body: { "SeriesId": "string", "SeasonNumber": number, "SkipExistingMarkers": boolean }

POST /CreditsDetector/ProcessLibrary

Process all TV shows in a library

Request Body: { "LibraryId": "string", "SkipExistingMarkers": boolean }

POST /CreditsDetector/TriggerDetection

Process all episodes in the library (queued sequentially)

Request Body: { "Limit": number }

POST /CreditsDetector/CancelDetection

Cancels the currently running detection process

POST /CreditsDetector/ClearQueue

Clears the processing queue

Detection Results & Status

GET /CreditsDetector/GetDetectionResults

Get detection results for episodes with filtering options

Query Parameters:

  • EpisodeId (string, optional) - Get result for specific episode
  • SeriesId (string, optional) - Get results for all episodes in series
  • SeasonNumber (number, optional) - Filter to specific season (requires SeriesId)
  • IncludeAllEpisodes (boolean) - Get results for all episodes in library

Response:

{
    "Success": true,
    "TotalEpisodes": 24,
    "EpisodesWithMarkers": 18,
    "Results": [
        {
            "EpisodeId": "string",
            "SeriesName": "string",
            "SeasonNumber": number,
            "EpisodeNumber": number,
            "EpisodeName": "string",
            "HasCreditsMarker": boolean,
            "CreditsStartSeconds": number,
            "CreditsStartFormatted": "00:18:45",
            "Duration": "00:22:30"
        }
    ]
}

GET /CreditsDetector/GetEpisodeDetectionResult

Get detailed detection result for a specific episode

Query Parameters: EpisodeId (string, required)

Response: Single episode result with full details

GET /CreditsDetector/GetProgress

Get current progress of credits detection operation

Response: Progress percentage, current episode, queue size

GET /CreditsDetector/GetSeriesMarkers

Get chapter markers for all episodes in a TV series

Query Parameters: SeriesId (string, required)

GET /CreditsDetector/GetSeasonValidation

Get validation data for all episodes in a season

Query Parameters: SeriesId (string, required), SeasonNumber (number, required)

GET /CreditsDetector/GetDetectionHistory

Get detection history for a series or episode

Query Parameters: SeriesId or EpisodeId, Limit (number, default 50)

Detection Methods & Configuration

GET /CreditsDetector/GetDetectionMethods

Get available detection methods and their current configurations

Response:

{
    "Success": true,
    "DetectionMode": "OcrOnly",
    "Methods": [
        {
            "Method": "OCR",
            "Enabled": true,
            "Primary": true,
            "Engine": "Tesseract",
            "Endpoint": "http://localhost:8884",
            "Languages": "eng+jpn",
            "Keywords": "...",
            "Settings": {
                "OcrSearchStartValue": 3.0,
                "OcrFrameRate": 0.5,
                "OcrEnableEpisodeComparison": true
            }
        },
        {
            "Method": "Chromaprint",
            "Enabled": false,
            "Primary": false
        }
    ]
}

Use this endpoint to discover available detection methods and their current settings before starting detection.

POST /CreditsDetector/TestOcrConnection

Test the OCR server connection

Request Body: { "OcrEndpoint": "string", "OcrEngine": "Tesseract|PaddleOCR" }

Dry Run & Testing

POST /CreditsDetector/DryRunSeries

Detect credits without saving markers (preview mode)

Request Body:

{
    "SeriesId": "string (optional)",
    "EpisodeId": "string (optional)",
    "LibraryId": "string (optional)",
    "SeasonNumber": number (optional),
    "SkipExistingMarkers": boolean
}

POST /CreditsDetector/DryRunSeriesDebug

Dry run with debug logging - captures detailed detection log

Request Body: Same as DryRunSeries

GET /CreditsDetector/GetDebugLog

Download the debug log from the last debug dry run

Response: Text file stream

Marker Management

POST /CreditsDetector/UpdateCreditsMarker

Update the credits marker timestamp for an episode

Request Body:

{
    "EpisodeId": "string",
    "CreditsStartSeconds": number,
    "IsRelativeFromEnd": boolean
}

POST /CreditsDetector/ApplyToSeason

Copy one episode's credits timestamp to all episodes in the season without markers

Request Body: { "EpisodeId": "string", "SeriesId": "string", "SeasonNumber": number }

POST /CreditsDetector/BatchUpdateSeasonMissingMarkers

Batch update credits timestamps for all episodes missing markers in a season

Request Body:

{
    "SeriesId": "string",
    "SeasonNumber": number,
    "CreditsStartSeconds": number,
    "IsRelativeFromEnd": boolean
}

POST /CreditsDetector/AddTimestampFromDryRun

Manually add a timestamp from a dry run detection

Request Body: { "EpisodeId": "string", "TimestampSeconds": number }

POST /CreditsDetector/ProcessSeasonMissingMarkers

Process only episodes missing credits markers in a specific season

Request Body: { "SeriesId": "string", "SeasonNumber": number }

Settings Override Reference

The SettingsOverride object in StartDetection supports the following parameters:

Detection Mode:

  • DetectionMode
  • OcrEngine
  • EnableAnimeDetection
  • AnimeDetectionMethod

OCR Configuration:

  • OcrEndpoint
  • OcrLanguages
  • OcrDetectionKeywords
  • OcrPageSegmentationMode
  • OcrEngineMode
  • OcrJpegQuality
  • OcrMaxResolutionHeight

OCR Search Parameters:

  • OcrSearchStartValue
  • OcrSearchStartUnit
  • OcrMinutesFromEnd
  • OcrFrameRate
  • OcrMinimumMatches
  • OcrMaxFramesToProcess
  • OcrMaxAnalysisDuration
  • OcrStopSecondsFromEnd
  • OcrMinimumConfidence

OCR Optimization:

  • OcrDelayBetweenFramesMs
  • OcrEnableParallelProcessing
  • OcrParallelBatchSize
  • OcrDelayBetweenBatchesMs
  • OcrEnableSmartFrameSkipping
  • OcrConsecutiveMatchesForEarlyStop

Episode Comparison:

  • OcrEnableEpisodeComparison
  • OcrEpisodeComparisonTolerance
  • OcrEpisodeComparisonMinimumEpisodes

Character Density Detection:

  • OcrEnableCharacterDensityDetection
  • OcrCharacterDensityThreshold
  • OcrCharacterDensityConsecutiveFrames
  • OcrCharacterDensityPrimaryMethod
  • OcrDensityRequireKeyword
  • OcrDensityKeywordWindowSeconds
  • OcrDensityRequireTemporalConsistency
  • OcrDensityMinimumDurationSeconds
  • OcrDensityRequireStyleConsistency
  • OcrDensityStyleConsistencyThreshold

Hardware Acceleration:

  • OcrEnableHardwareAcceleration
  • OcrHardwareAccelerationType
  • OcrHardwareDevice
  • OcrUseHardwareOutputFormat
  • OcrUseHardwareFilters
  • OcrUseDirectMemoryPipeline

Black Frame Detection:

  • BlackFrameMinimumPercentage
  • BlackFrameThreshold

Chromaprint Settings:

  • ChromaprintFingerprintSimilarityThreshold
  • ChromaprintEnableEpisodeComparison
  • ChromaprintEpisodeComparisonTolerance
  • ChromaprintEpisodeComparisonMinimumEpisodes
  • ChromaprintStopSecondsFromEnd

Performance:

  • CpuUsageLimit
  • CpuThrottleDelayMs
  • LowerThreadPriority
  • LowerProcessPriority

Video Validation:

  • EnableVideoValidation
  • VideoValidationTimeoutSeconds

API Usage Tips

  • Use GetDetectionMethods to discover current configuration before making requests
  • Test settings with DryRun mode before processing large libraries
  • Use StartDetection with SettingsOverride for one-off detection with custom parameters
  • Monitor progress with GetProgress during long-running operations
  • Enable caching by setting SkipExistingMarkers to true to avoid reprocessing
  • Use GetDetectionResults to retrieve and analyze detection outcomes
