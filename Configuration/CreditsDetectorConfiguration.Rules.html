Detection Rules

Create custom detection settings for specific series, tags, studios, or libraries. When a series matches a rule it uses those settings instead of the defaults. Adding a library to a rule alongside studios, tags, or series names limits the rule to shows in that library only; it does not make the rule match every show in the library.

How Rules Work

  • Rules match TV series by name, tags, studios, and/or libraries
  • Series name matching has the highest priority, followed by tags and studios (equal priority), then library-only rules
  • If multiple rules match at the same priority, the rule listed first wins
  • Only settings specified in a rule will override defaults; everything else uses default values
  • Rules work for both batch processing and single episode scanning
  • Series names, tags, and studios are case-insensitive

How Libraries Work in Rules

  • Combined with studios, tags, or series names: the library acts as a scope filter — the series must match the studio/tag/name AND be in the selected library
  • Used alone (no other matchers): matches every show inside the selected library
