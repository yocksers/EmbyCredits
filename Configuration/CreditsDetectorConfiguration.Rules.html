Detection Rules

Create custom detection settings for specific tags or studios. When a video matches a rule's tag or studio, those settings will be used instead of the default settings.

How Rules Work

  • Rules are matched against TV series tags and studios
  • If multiple rules match, the first matching rule is used
  • Only settings specified in a rule will override defaults (unconfigured settings use default values)
  • Rules work for both batch processing and single episode scanning
  • Tags and studios are case-insensitive
