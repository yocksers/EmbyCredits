Docker Setup Guide

What is OCR Detection?

This plugin uses Optical Character Recognition (OCR) to detect credits by reading text from video frames. It supports two OCR engines: Tesseract and PaddleOCR. Choose the engine in the OCR Enhancements tab.

Option 1: Tesseract OCR (Default)

Traditional OCR engine with extensive language support.

Step 1: Install Docker

If you don't have Docker installed:

  • Windows: Download Docker Desktop for Windows
  • Linux: Install Docker Engine from your package manager

Step 2: Pull the Tesseract Docker Image

Open a terminal/PowerShell and run:

docker pull yock1/embycreditocr

Step 3: Start the Tesseract Container

docker run -d --name tesseract-ocr -p 8884:8884 --restart unless-stopped yock1/embycreditocr

Docker Compose Example:

Create a file named docker-compose.yml:

version: '3'
services:
  tesseract:
    image: yock1/embycreditocr
    container_name: tesseract-ocr
    ports:
      - "8884:8884"
    restart: unless-stopped

Then run: docker-compose up -d

Step 4: Verify the Container is Running

docker ps

You should see the tesseract-ocr container running on port 8884.

Test the OCR service:

curl http://localhost:8884/status

Option 2: PaddleOCR with GPU Support (Alternative)

Deep learning based OCR with excellent multi-language support and GPU acceleration for faster processing.

⚠️ Requirements:
  • NVIDIA GPU only (requires CUDA support)
  • ~20GB disk space (large image with GPU libraries)
  • Docker Desktop with GPU support enabled (Windows: WSL2 backend)

Step 1: Pull and Run PaddleOCR GPU Container

docker pull yock1/embycreditpaddle
docker run -d --gpus all --name paddleocr -p 8884:8884 --restart unless-stopped yock1/embycreditpaddle

Docker Compose Example:

version: '3.8'
services:
  paddleocr:
    image: yock1/embycreditpaddle
    container_name: paddleocr
    ports:
      - "8884:8884"
    environment:
      - USE_GPU=true
      - USE_ANGLE_CLS=true
      - OCR_LANG=en
    volumes:
      # For Unraid: Persist models outside docker image
      - /mnt/user/appdata/paddleocr-models:/root/.paddleocr
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]
    restart: unless-stopped

Step 2: Configure PaddleOCR in Plugin

  • Go to the Settings tab
  • Set OCR Engine to PaddleOCR
  • Set OCR API Endpoint to http://localhost:8884
  • Click Test Connection to verify it's working

💡 Tip: PaddleOCR with GPU acceleration is significantly faster than Tesseract for processing large video libraries.

Step 5: Configure the Plugin

  • OCR Engine: Choose between Tesseract or PaddleOCR in the Settings tab
  • OCR API Endpoint: http://localhost:8884 (default port for both engines)
  • Custom Temp Folder Path: CRITICAL for Docker users! Set a custom temp folder path in Settings tab to prevent filling up Docker images with temp files

Recommended Settings for Best Performance

  • Search Start Position: 2-3 minutes from end (skips to near the end for faster processing)
  • Frame Rate: 0.5 fps (1 frame every 2 seconds - optimal speed/accuracy balance)
  • Max Analysis Duration: 600 seconds (10 minutes - prevents runaway processing)
  • Minimum Matches: 2 (requires 2 keyword matches within 10 seconds)

How It Works

The plugin extracts video frames using FFmpeg, sends them to your selected OCR server (Tesseract or PaddleOCR), and searches for credit keywords (like "created by", "produced by", "directed by"). When it finds sustained keyword matches, it marks that as the credit start time.
