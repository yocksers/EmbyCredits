🐳 Docker Setup Guide

What is OCR Detection?

This plugin uses Optical Character Recognition (OCR) to detect credits by reading text from video frames. It requires a Tesseract OCR server running in Docker to analyze the video frames.

Step 1: Install Docker

If you don't have Docker installed:

  • Windows: Download Docker Desktop for Windows
  • Linux: Install Docker Engine from your package manager

Step 2: Pull the Tesseract Docker Image

Open a terminal/PowerShell and run:

docker pull yock1/embycreditocr

Step 3: Start the Tesseract Container

Standard (CPU-only) Version:

docker run -d --name tesseract-ocr -p 8884:8884 --restart unless-stopped yock1/embycreditocr

GPU-Accelerated Version:

Nvidia GPU:

docker run -d --name tesseract-ocr --gpus all -p 8884:8884 --restart unless-stopped yock1/embycreditocr-gpu:latest

Intel/AMD GPU:

docker run -d --name tesseract-ocr --device /dev/dri:/dev/dri -p 8884:8884 --restart unless-stopped yock1/embycreditocr-gpu:latest

GPU Container (CPU fallback mode):

docker run -d --name tesseract-ocr -p 8884:8884 --restart unless-stopped yock1/embycreditocr-gpu:latest

Docker Compose Example (Standard):

Create a file named docker-compose.yml:

version: '3'
services:
  tesseract:
    image: yock1/embycreditocr
    container_name: tesseract-ocr
    ports:
      - "8884:8884"
    restart: unless-stopped

Docker Compose Example (Nvidia GPU):

version: '3'
services:
  tesseract:
    image: yock1/embycreditocr-gpu:latest
    container_name: tesseract-ocr
    ports:
      - "8884:8884"
    restart: unless-stopped
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu, compute, utility, graphics]

Docker Compose Example (Intel/AMD GPU):

version: '3'
services:
  tesseract:
    image: yock1/embycreditocr-gpu:latest
    container_name: tesseract-ocr
    ports:
      - "8884:8884"
    restart: unless-stopped
    devices:
      - /dev/dri:/dev/dri

Then run: docker-compose up -d

Step 4: Verify the Container is Running

docker ps

You should see the tesseract-ocr container running on port 8884.

Test the OCR service:

curl http://localhost:8884/status

For GPU version, verify GPU access (Nvidia only):

docker exec tesseract-ocr nvidia-smi

Step 5: Configure the Plugin

  • OCR Endpoint: http://localhost:8884 (if on same machine) or http://HOST_IP:8884
  • Custom Temp Folder Path: CRITICAL for Docker users! Set a custom temp folder path in Settings tab to prevent filling up Docker images with temp files

Recommended Settings for Best Performance

  • Search Start Position: 2-3 minutes from end (skips to near the end for faster processing)
  • Frame Rate: 0.5 fps (1 frame every 2 seconds - optimal speed/accuracy balance)
  • Max Analysis Duration: 600 seconds (10 minutes - prevents runaway processing)
  • Minimum Matches: 2 (requires 2 keyword matches within 10 seconds)

How It Works

The plugin extracts video frames using FFmpeg, sends them to the Tesseract OCR server, and searches for credit keywords (like "created by", "produced by", "directed by"). When it finds sustained keyword matches, it marks that as the credit start time.
