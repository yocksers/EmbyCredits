expand_more Anime Detection

Specialized detection for anime shows using black frame detection optimized for anime credit sequences. When enabled, anime shows are automatically detected and use black frame detection first before falling back to standard methods.

Recommended: Enabled (default). Automatically detects anime series (by checking Tags or Genres for "anime") and uses optimized detection methods. Anime shows will use black frame detection first, then fall back to your configured detection mode (Hash/OCR) if needed.
Default: Black Frame Detection. Choose which detection method to use for anime shows. Black Frame is optimized for anime credit sequences that commonly have black frames. OCR uses text recognition which may work better for some anime. If the selected method fails, it will fall back to your configured Detection Mode (Hash/OCR).
Default: 85%. Minimum percentage of pixels that must be black for a frame to be considered a black frame (0-100). Higher values require darker/more complete black frames.
Default: 28. Pixel brightness threshold (0-255) - pixels darker than this are considered black. Lower values require darker pixels. 0 = completely black, 255 = white.

expand_more Hash Detection (Chromaprint)

Audio fingerprinting and black frame/silence detection for credits detection. Faster than OCR but may be less accurate. Works well for anime and shows with consistent credit music.

Credits Duration Settings

Default: 15 seconds. Minimum duration for detected credits sequence. Credits shorter than this will be rejected.
Default: 120 seconds. Maximum duration for detected credits sequence. Credits longer than this will be rejected.
Default: 25%. Analyze this percentage from the end of each episode. For example, 25% means analyze the last quarter of the video.

Audio Fingerprinting

Recommended: Disabled (default). Use chromaprint audio fingerprinting to compare audio patterns across episodes. This is more accurate than black frame/silence detection but requires more processing. Falls back to black frame/silence detection if fingerprinting fails.
Default: 360 seconds. Length of audio to fingerprint for comparison. Longer durations are more accurate but slower.
Default: 0.90. Minimum similarity (0.0-1.0) between audio fingerprints to be considered a match. Higher values require closer matches.

Episode Comparison

Recommended: Enabled (default). Compare episodes within the same season to speed up detection. After processing multiple episodes, the plugin learns where credits typically start and narrows the search window for new episodes. This makes detection significantly faster while maintaining accuracy.
Default: 15 seconds. When comparing episodes, start searching this many seconds BEFORE the average credits timestamp. Higher values = safer but slightly slower. Example: If previous episodes had credits at 22:00, with 15s tolerance, start searching at 21:45 and scan to end of video.
Default: 4 episodes. Episode comparison will activate after this many episodes in a season have been processed. Lower values (2-3) activate comparison sooner for faster processing. BlackFrame detection uses 2 episodes minimum.

Default: 0.5 seconds. Minimum duration a black frame must persist to be considered a credits boundary.

Silence Detection Refinement

Default: -50dB. Audio level threshold for silence detection. More negative values detect quieter sounds as silence.
Default: 0.5 seconds. Minimum duration of silence required to be considered a credits boundary.
Default: 30 seconds. How far before and after the fingerprint-detected timestamp to search for silence periods.

Character Density Detection

Smart Detection: Instead of relying solely on keywords, this detects credits by identifying frames with high text density. Credits typically have 50-200+ characters per frame, while regular content has very few. This works regardless of which specific words appear in the credits.
Detect credits based on high text density rather than specific keywords (highly recommended)
When enabled, density detection is the main method and keywords are optional. When disabled, keywords are required but density boosts confidence.
Recommended: 20. Frames with this many characters or more are considered potential credits. Typical: Pre-credits ~5 chars, Credits ~100+ chars
Recommended: 3. How many consecutive frames must exceed the threshold to confirm credits (prevents false positives from occasional text overlays)
